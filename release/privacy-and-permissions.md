# Privacy and network use

## What the plugin sends

- The search text and the App Store region are sent to Apple’s iTunes Search API (`https://itunes.apple.com/*`).
- When you insert an icon, the PNG is downloaded from Apple CDN hosts (`https://*.mzstatic.com/*`).
- Uwarp / Sherotree does not receive searches, regions, or icon files.

## What stays local

- Selected region and recent searches are stored in Sketch settings on this Mac.
- Removing the plugin clears those values (Sketch settings for this identifier).
