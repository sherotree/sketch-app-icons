# Listing copy (Sketch directory / homepage)

**Name:** App Icons Finder  
**Author:** Uwarp  
**Version:** 1.0.0  
**Identifier:** design.uwarp.sketch.app-icons

**One-liner:** Search the App Store and insert official app icons as PNG.

**Description:**

App Icons Finder searches the Apple App Store and inserts an official app icon as a PNG into your Sketch document.

Type an app name, choose a store region, and pick a result. Insert PNG places a 128×128 image on the selected frame or group, or on the current page.

Search text is sent to Apple so the results stay current. The plugin does not send searches to Uwarp.

App icons belong to their publishers. Use this for design reference, and get permission before you publish an icon.
